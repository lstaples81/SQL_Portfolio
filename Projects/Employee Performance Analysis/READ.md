# Employee Performance Analysis

## Overview
This project analyzes employee and departmental data using SQL Server to evaluate workforce performance, salary distribution, and organizational structure.

The goal is to transform employee data into actionable insights that support HR decision-making, compensation planning, and workforce optimization.

---

## Objectives
- Analyze salary distribution across departments
- Identify top-performing and high-compensation employees
- Evaluate employee distribution by department
- Measure employee tenure and experience levels
- Detect salary disparities and potential imbalances

---

## Tools & Technologies
- SQL Server
- GitHub

---

## Technical Skills Demonstrated
- Aggregations (AVG, COUNT, SUM) for workforce metrics
- CASE statements for employee classification
- Window functions (RANK, OVER) for salary ranking
- Common Table Expressions (CTEs) for structured analysis
- Date functions (DATEDIFF) for tenure calculation
- JOINs for multi-table analysis

---

## Key Analysis Performed
- Average salary by department
- Employee count per department
- Top 10 highest-paid employees
- Salary ranking within departments
- Identification of employees above average salary
- Employee tenure analysis based on hire date

---

## Key Insights
- Salary distribution varies significantly across departments
- High-performing employees often align with higher compensation
- Smaller departments may have higher average salaries
- Tenure can correlate with compensation levels

---

## Business Impact
- Supports HR in compensation and salary planning
- Identifies pay disparities across departments
- Assists in workforce planning and resource allocation
- Enables data-driven employee performance evaluation

---

## How to Use
1. Open SQL Server
2. Run the queries in `queries.sql`
3. Review outputs to analyze workforce metrics and performance
