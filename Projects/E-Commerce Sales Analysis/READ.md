# E-Commerce Sales Analysis

## Objective
Analyze e-commerce sales data to understand customer behavior, revenue trends, and top-performing products.

## Tools Used
- SQL Server
- Excel / Tableau (optional)

## SQL Skills Used
- JOINs
- GROUP BY
- Aggregations
- CTEs
- Window Functions

## Key Analysis
- Total revenue by customer
- Top 10 customers
- Best-selling products
- Monthly sales trends

## Key Insights
- Top 10 customers contribute a large portion of revenue
- Certain product categories dominate sales
- Seasonal trends affect revenue

## How to Use
Run SQL queries from `queries.sql` in any SQL environment.
